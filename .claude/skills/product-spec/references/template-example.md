### 1-2. 문제

- 현재 상황
    - 홈과 포지션 상세에 추천 포지션을 보여주지만 왜 추천했는지는 보여주지 않음
- 유저가 겪는 어려움
    - 구직 유저가 추천 포지션이 나와 맞는지 열어 보기 전에는 알 수 없음
    - 구직 유저가 맞지 않는 추천을 알릴 방법이 없음
- 데이터
    - 추천 포지션 클릭률 2.1%, 검색 결과 클릭률 4.8%

### 1-3. 사용자 니즈

- 구직 유저
    - 추천된 포지션이 나와 왜 맞는지 보고, 지원할지 빨리 정하고 싶음
    - 맞지 않는 추천은 덜 보고 싶음

### 1-4. 가설

- **IF** 추천 포지션마다 왜 추천했는지 근거를 보여주고, 맞지 않는 추천을 알릴 수 있게 하면
- **THEN** 유저가 추천 포지션을 더 자주 열고 지원한다
- **BECAUSE** 유저가 근거를 보고 내 상황과 맞는지 바로 판단하고, 유저 피드백으로 다음 추천이 나아짐

### 1-5. 솔루션

- 근거 표기
    - 추천 포지션마다 우선순위가 가장 높은 근거 1개를 보여줌
- 근거 상세
    - 화면을 옮기지 않고 근거를 최대 3개까지 확인
- 추천 그만 보기
    - 맞지 않는 근거를 알리면 다음 추천부터 같은 근거의 포지션을 줄임

## 3. 구현 상세

| # | 진입점 | 화면 | 기능 | 요구사항 |
| --- | --- | --- | --- | --- |
| 1 | 홈 진입 | 홈 > 추천 포지션 카드<br>(현재 화면 캡처) | 근거 표기 | - 노출 조건: 근거 코드가 1개 이상인 추천 포지션<br>- 동작<br>  - 추천 포지션마다 근거 1개를 보여줌<br>  - 근거 코드가 여럿이면 근거 코드 표의 우선순위가 가장 높은 것<br>- 유지하는 것: 근거 코드가 없는 카드는 지금 카드 그대로<br>- ⚠️ 착수 조건: 추천 목록 응답에 포지션별 근거 코드를 넣을 수 있는지 → 추천 모델팀 확인 필요 |
| 2 | 포지션 상세 하단 | 포지션 상세 > 하단 추천 카드<br>(현재 화면 캡처) | 근거 표기 | - 동작: 홈과 같은 규칙<br>- 노출 조건: 지금 보고 있는 포지션과 같은 직무라는 이유만으로 생긴 근거는 보여주지 않음 |
| 3 | 근거 표기를 누름 | 근거 상세 (신규) | 근거 상세 | - 동작<br>  - 화면을 옮기지 않고 확인<br>  - 근거를 우선순위 순으로 최대 3개<br>  - 근거마다 근거 코드 표의 '상세에서 알릴 내용'<br>  - 여기서 할 수 있는 일: 포지션 상세로 이동, 추천 그만 보기 |
| 4 | 근거 상세에서 추천 그만 보기 | 근거 상세 (신규) | 추천 그만 보기 | - 대상: 로그인 유저<br>- 동작<br>  - 누른 포지션은 추천 목록에서 바로 빠짐<br>  - 추천을 줄인다는 것을 유저에게 알림<br>  - 다음 추천부터 같은 근거 코드로 추천된 포지션을 줄임 → 줄이는 방법은 개발 제안 요청<br>- 그만 보기를 되돌리는 기능은 이번에 만들지 않음 (PO 확인 필요) |
| 5 | 해당 없음 (추천 목록 조회) | 해당 없음 (서버) | 근거 코드 계산 | - 동작<br>  - 서버가 포지션마다 근거 코드 0~3개를 우선순위 순으로 내려줌<br>  - 근거에 넣을 값(직무명, 스킬명, 기업명, 경력 년차)도 함께<br>- 케이스<br>  - 이력서가 없는 유저: 보유 스킬 일치 근거를 만들지 않음 |

| 근거 코드 | 우선순위 | 표기에서 알릴 내용 | 상세에서 알릴 내용 |
| --- | --- | --- | --- |
| 최근 지원과 같은 직무 | 1 | 최근 지원한 직무와 같음 | 최근 30일 안에 지원한 포지션의 직무명 |
| 보유 스킬 일치 | 2 | 내 스킬 몇 개와 맞는지 | 이력서 스킬 중 이 포지션이 찾는 스킬 이름 |
| 관심 기업 | 3 | 관심 기업의 포지션 | 관심 기업으로 등록한 기업명 |
| 비슷한 유저 지원 | 4 | 비슷한 경력의 유저가 많이 지원함 | 경력 년차와 직무명, 최근 7일 기준 |

| 이벤트 | 시점 | property | 기존/신규 |

| 추천 그만 보기 | 유저가 추천 그만 보기를 누를 때 | 근거 코드, 포지션 ID | 신규 (이벤트명 데이터팀 확인 필요) |

## 4. 용어 정의

| 용어 | 설명 | 화면 상 노출되는 문구 |
| --- | --- | --- |
| 근거 코드 | - 이 포지션을 왜 추천했는지 나타내는 값<br>- 포지션마다 0~3개 | 화면에 노출하지 않음 |
