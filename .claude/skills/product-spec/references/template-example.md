### 1-2. 문제

- 구직 유저의 추천 이용
    - 추천 포지션 클릭률이 검색 결과보다 낮음 (가상 수치: 추천 2.1%, 검색 4.8%, 쿼리 첨부 필요)
    - 유저는 왜 이 포지션이 추천됐는지 알 수 없어, 맞지 않는 추천이 이어지면 추천 영역을 건너뜀
    - 유저가 맞지 않는 추천을 알릴 방법이 없어 추천이 나아지지 않음

### 1-3. 사용자 니즈

- 구직 유저
    - 추천된 포지션이 나와 왜 맞는지 보고, 지원할지 빨리 정하고 싶음
    - 맞지 않는 추천은 덜 보고 싶음

### 1-4. 가설

- **IF** 추천 카드마다 왜 추천했는지 한 줄 근거를 보여주고, 맞지 않는 추천을 알릴 수 있게 하면
- **THEN** 유저가 추천 포지션을 더 자주 열고 지원한다
- **BECAUSE** 유저가 근거를 보고 내 상황과 맞는지 바로 판단하고, 유저 피드백으로 다음 추천이 나아짐

### 1-5. 솔루션

- 근거 라벨
    - 추천 카드마다 우선순위가 가장 높은 근거 1개를 한 줄로 보여줌
- 근거 바텀시트
    - 라벨을 누르면 근거를 최대 3개까지 보여줌. 화면을 옮기지 않고 판단할 수 있게 바텀시트로
- 추천 그만 보기
    - 맞지 않는 근거를 알리면 다음 추천부터 같은 근거의 포지션을 줄임

## 2. 용어

| 용어 | 뜻 |
| --- | --- |
| 근거 코드 | - 이 포지션을 왜 추천했는지 나타내는 값<br>- 포지션마다 0~3개 |
| 근거 라벨 | - 추천 카드 이미지 아래에 붙는 한 줄 문구<br>- 근거 코드 중 우선순위가 가장 높은 것 1개 |
| 근거 바텀시트 | - 근거 라벨을 누르면 열리는 화면<br>- 근거를 최대 3개까지 보여줌 |

### 2-1. 근거 코드

| 근거 코드 | 우선순위 | 근거 라벨 문구 | 바텀시트 상세 문구 |
| --- | --- | --- | --- |
| 최근 지원과 같은 직무 | 1 | '최근 지원한 직무와 같아요' (문구 워싱 필요) | '최근 30일 안에 지원한 {직무명} 포지션과 같은 직무예요' (문구 워싱 필요) |
| 보유 스킬 일치 | 2 | '내 스킬 {N}개와 맞아요' (문구 워싱 필요) | '이력서 스킬 중 {스킬1}, {스킬2}가 이 포지션에서 찾는 스킬이에요' (문구 워싱 필요) |
| 관심 기업 | 3 | '관심 기업의 포지션이에요' (문구 워싱 필요) | '{기업명}을 관심 기업으로 등록했어요' (문구 워싱 필요) |

## 4. 구현 상세

| # | 진입점 | 화면 | 기능 | 요구사항 |
| --- | --- | --- | --- | --- |
| 1 | 홈 진입 | 홈 > 추천 포지션 카드<br>(현재 화면 캡처) | 근거 라벨 | - 카드 이미지 아래, 포지션명 위에 근거 라벨 1개<br>- 근거 코드가 여럿이면 2-1 근거 코드 표의 우선순위가 가장 높은 것<br>- 근거 코드가 없으면 라벨 없이 지금 카드 그대로<br>- 한 줄을 넘으면 말줄임<br>- ⚠️ 착수 조건: 추천 목록 응답에 포지션별 근거 코드를 넣을 수 있는지 → 추천 모델팀 확인 필요 |
| 2 | 포지션 상세 하단 | 포지션 상세 > 하단 추천 카드<br>(현재 화면 캡처) | 근거 라벨 | - 홈과 같은 규칙<br>- 지금 보고 있는 포지션과 같은 직무라는 이유만으로 생긴 근거는 보여주지 않음 |
| 3 | 근거 라벨 누름 | 근거 바텀시트 (신규) | 근거 상세 | - 제목: '이 포지션을 추천한 이유' (문구 워싱 필요)<br>- 근거를 우선순위 순으로 최대 3개, 2-1 근거 코드 표의 바텀시트 상세 문구<br>- 하단 버튼: '포지션 보기' (포지션 상세로 이동), '이런 추천 그만 보기' |
| 4 | 근거 바텀시트 '이런 추천 그만 보기' | 근거 바텀시트 (신규) | 추천 그만 보기 | - 누르면 바텀시트가 닫히고 토스트 '앞으로 이런 추천을 줄일게요' (문구 워싱 필요)<br>- 그 카드는 목록에서 바로 빠짐<br>- 다음 추천부터 같은 근거 코드로 추천된 포지션을 줄임<br>  - 줄이는 방법 → 개발 제안 요청<br>- 비로그인 유저에게는 버튼을 보여주지 않음<br>- 그만 보기를 되돌리는 화면은 이번에 만들지 않음 (PO 확인 필요) |
| 5 | 해당 없음 (추천 목록 조회) | 해당 없음 (서버) | 근거 코드 계산 | - 서버가 포지션마다 근거 코드 0~3개를 우선순위 순으로 내려줌<br>- 문구에 넣을 값(직무명, 스킬명, 기업명, 경력 년차)도 함께<br>- 이력서가 없는 유저는 보유 스킬 일치 근거를 만들지 않음 |
