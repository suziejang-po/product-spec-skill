# 도서 대여 앱 반납 알림

## 용어

| 용어 | 뜻 | 코드 식별자 (출처) |
|---|---|---|
| 대여 | 유저가 도서관에서 책을 빌린 상태. 기본 14일 | rental (src/models/rental.ts, 기존) |
| 반납 예정일 | 대여일 + 14일. 연장 시 + 7일 | rental.due_at (기존) |
| 반납 알림 | 반납 예정일 3일 전과 당일에 보내는 푸시 | notification.type = RETURN_DUE (신규 제안) |
| 내 서재 | 대여 중인 책 목록 화면 | /my/books (app/my/books/page.tsx, 기존) |
| 연장 | 반납 예정일을 7일 미룸. 1회만 | POST /rentals/{id}/extend (기존) |

## 문제

- 최근 90일 대여 12,400건 중 연체 2,170건(17.5%). BQ `library.rentals`, 쿼리는 인라인 댓글
- 연체 유저 설문(n=212)에서 "반납일을 잊었다" 61%. 설문 결과 링크 [설문](https://example.com/survey)
- 반납 예정일은 내 서재 화면에만 표시되고 알림이 없음

## 사용자 니즈

- 반납일을 따로 기억하지 않아도 제때 돌려주고 싶음
- 못 돌려줄 것 같으면 그 자리에서 연장하고 싶음

## 가설과 KR

- IF 반납 예정일 3일 전과 당일에 푸시를 보내고 알림에서 바로 연장하게 하면
- THEN 연체율이 내려갈 것이다
- BECAUSE 연체 원인의 61%가 잊음이고, 연장 기능은 이미 있으나 진입점이 내 서재뿐

| 구분 | 지표 | 현재 | 목표 | 측정 | 근거 |
|---|---|---|---|---|---|
| Primary | 연체율 (반납 예정일 D+1 기준) | 17.5% | 12% | 연체 건수 / 대여 건수, 주간 | BQ library.rentals, 인라인 댓글 쿼리 |
| Secondary | 알림 클릭률 | 없음 | ⚠️ 목표 확정 필요 → DRI | notification__return_due__click / send | 신규 이벤트 |
| Guardrail | 푸시 수신 거부율 | 3.1% | 상승 없음 | 설정 화면 off 전환 / 전체 유저 | Amplitude 차트 [링크](https://example.com/chart) |

## 솔루션

반납 예정일 3일 전과 당일 오전 9시에 푸시를 보내고, 알림을 누르면 내 서재의 해당 책으로 이동해 연장 버튼을 바로 누를 수 있게 한다. 새 화면은 만들지 않는다.

## 구현 범위 요약

- 반납 알림 푸시 2회 신설, 알림 탭 시 내 서재 해당 책으로 이동. 신규 화면 없음

| 항목 | 링크 |
|---|---|
| Design | https://www.figma.com/design/xxxx?node-id=1-2 |

| 페이지 | 변경 |
|---|---|
| 내 서재 | 기존 화면 수정. 알림 진입 시 해당 책 카드로 스크롤과 강조 |
| 알림 설정 | 기존 화면 수정. 반납 알림 on/off 항목 추가 |

| depth1 | depth2 | 노출 조건 | 주요 기능 |
|---|---|---|---|
| 내 서재 | 대여 중 | 로그인 유저 | 대여 목록, 연장 |
| 설정 | 알림 설정 | 로그인 유저 | 마케팅 알림, 반납 알림 on/off |

## 구현 상세

| # | 진입점 | 화면 | 기능 | 요구사항 |
|---|---|---|---|---|
| 1 | 반납 예정일 3일 전, 당일 오전 9시 (서버 스케줄) | 푸시 알림 (신규) | 반납 알림 발송 | 1. 대상: 대여 중이고 반납 알림 on인 유저<br>2. 문구 3일 전 '{책 제목} 반납일이 3일 남았어요', 당일 '{책 제목} 오늘 반납일이에요'<br>3. 같은 유저에게 같은 날 책이 여러 권이면 1건으로 묶고 '외 N권' 표기<br>4. 발송 실패는 재시도 없이 기록만<br>⚠️ 오전 9시가 아닌 시간대 유저 처리 → 개발 제안 요청 |
| 2 | 푸시 알림 탭 | 내 서재 (기존 수정) | 해당 책으로 이동 | 1. 딥링크 /my/books?rental={id}<br>2. 해당 카드로 스크롤 후 2초간 배경 강조<br>3. 이미 반납된 책이면 강조 없이 목록만 표시 |
| 3 | 내 서재 책 카드 | 내 서재 (변경 없음) | 연장 | 1. 기존 연장 버튼 그대로. 1회 제한, 연장 후 반납 예정일 +7일 |
| 4 | 설정 > 알림 설정 | 알림 설정 (기존 수정) | 반납 알림 on/off | 1. 기본값 on<br>2. off면 발송 대상에서 제외. 즉시 반영 |
| 5 | 발송과 탭 | 전체 | 이벤트 | 1. notification__return_due__send: property daysLeft(3 또는 0), bookCount<br>2. notification__return_due__click: property daysLeft |

## 제약과 참고

- 푸시 발송량 하루 최대 5만 건 (인프라 제한). 대상이 넘으면 3일 전 알림부터 줄임
- 폐기: 이메일 알림. 열람률 4%로 재사용 금지
- 연장 API 스펙 [링크](https://example.com/api/rentals)
