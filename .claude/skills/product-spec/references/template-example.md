### 1-2. 문제

- 추천 포지션 클릭률이 검색 결과보다 낮음 (가상 수치: 추천 2.1%, 검색 4.8%) ⚠️ 쿼리 첨부 필요
- 유저는 왜 이 포지션이 추천됐는지 알 수 없어, 맞지 않는 추천이 이어지면 추천 영역을 건너뜀
- 유저가 맞지 않는 추천을 알릴 방법이 없어 추천이 나아지지 않음

### 1-3. 사용자 니즈

- 구직 유저
    - 추천된 포지션이 나와 왜 맞는지 보고, 지원할지 빨리 정하고 싶음
    - 맞지 않는 추천은 덜 보고 싶음
- 원티드
    - 추천 영역에서 지원까지 이어지는 유저를 늘리고 싶음

⚠️ 유저 니즈 근거 없음 → PO 확인 필요

### 1-4. 가설

- **IF** 추천 카드마다 왜 추천했는지 한 줄 근거를 보여주고, 맞지 않는 추천을 알릴 수 있게 하면
- **THEN** 유저가 추천 포지션을 더 자주 열고 지원한다
- **BECAUSE** 유저가 근거를 보고 내 상황과 맞는지 바로 판단하고, 유저 피드백으로 다음 추천이 나아짐

### 1-5. 솔루션

- 근거 라벨: 추천 카드마다 우선순위가 가장 높은 근거 1개를 한 줄로 보여줌
- 근거 바텀시트: 유저가 라벨을 누르면 근거를 최대 3개까지 보여줌
- 추천 그만 보기: 유저가 맞지 않는 근거를 알리면 다음 추천부터 같은 근거의 포지션을 줄임

## 2. 용어

| 용어 | 뜻 |
| --- | --- |
| 추천 포지션 | - 홈과 포지션 상세 하단에 보이는 유저 맞춤 포지션 목록<br>- 한 번에 최대 20개 |
| 근거 코드 | - 이 포지션을 왜 추천했는지 나타내는 값<br>- 포지션마다 0~3개 |
| 근거 라벨 | - 추천 카드 이미지 아래에 붙는 한 줄 문구<br>- 근거 코드 중 우선순위가 가장 높은 것 1개 |
| 근거 바텀시트 | - 유저가 근거 라벨을 누르면 열리는 화면<br>- 근거를 최대 3개까지 보여줌 |
| 추천 그만 보기 | - 근거 바텀시트에서 누르는 버튼<br>- 같은 근거로 추천된 포지션을 다음 추천부터 줄임 |

| 3 | 근거 라벨 누름 | 근거 바텀시트 (신규 생성) | 근거 상세 | 1. 제목: '이 포지션을 추천한 이유' (문구 워싱 필요)<br>2. 근거를 우선순위 순으로 최대 3개, 2-1 근거 코드 표의 바텀시트 상세 문구<br>3. 하단 버튼: '포지션 보기' (포지션 상세로 이동), '이런 추천 그만 보기'<br>4. 유저가 바깥을 누르거나 아래로 내리면 닫힘 |
