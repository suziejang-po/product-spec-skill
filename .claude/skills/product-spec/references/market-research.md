# 외부 사례 리서치

다른 회사의 같은 서비스, 비슷한 서비스, 외부 동향 중 수치나 사실로 확인되는 것만 찾는다. 스펙의 판단 근거를 보태는 용도. 경쟁사 분석 보고서를 쓰지 않는다

## 언제 하는가

- New Product, Feature, 실험: Phase 0 마지막에 찾아 두고, 후보는 초안을 낸 뒤 Phase 3 질문과 함께 보여줌 (초안이 먼저)
- Enhancement: 작성자가 요청할 때만
- 웹 검색 도구가 없으면 건너뛰고 채팅에 한 줄: "웹 검색 도구가 없어 외부 사례 리서치를 건너뜁니다"
- 작성자가 "외부 사례 빼고"라고 하면 하지 않는다

## 찾는 것

1. 같은 서비스: 국내외 채용 플랫폼, HR SaaS에서 같은 기능을 낸 곳 (예: 지원자 스크리닝이면 다른 채용 플랫폼의 자동 스크리닝)
2. 비슷한 서비스: 다른 업종이지만 같은 문제를 푼 곳 (예: 응답 지연 문제면 마켓플레이스의 판매자 응답률 정책)
3. 외부 동향: 시장 조사, 정부 통계, 공개 리서치에서 이 문제와 직접 닿는 수치

검색어는 기능 이름 하나로 끝내지 않는다. 문제의 유저 어려움을 그대로 검색어로도 쓴다 (예: "채용 결과 통보 지연", "candidate ghosting")

## 기간 기준

- 기본: 오늘 기준 최근 12개월 안에 나온 것
- 12개월 안에 없으면 24개월까지 넓히고, 표의 날짜 칸에 그대로 적는다
- 24개월을 넘은 것은 쓰지 않는다
- 날짜를 확인할 수 없는 자료는 쓰지 않는다
- 기능 출시 사례는 출시 날짜, 수치는 조사나 발표 날짜를 쓴다

## 출처 기준

쓰는 것
- 회사 공식 발표, 보도자료, 공식 블로그, 도움말 문서, 앱 업데이트 노트
- 공시, IR 자료
- 정부, 공공기관 통계
- 조사 기관 리포트 (조사 대상과 표본 수가 적힌 것)
- 언론 기사는 위 자료를 인용한 경우만. 원 자료를 찾을 수 있으면 원 자료를 쓴다

쓰지 않는 것
- 출처나 조사 방법이 없는 수치
- 개인 블로그, 커뮤니티 글, 광고성 비교 글
- 검색 결과 요약만 보고 원문을 열지 않은 것

## 정리 방법

1. 찾은 것마다 원문을 열어 수치, 날짜, 대상을 직접 확인한다
2. 한 사례당 한 줄로 채팅에 후보 목록을 보여준다. 최대 8개
   ```
   외부 사례 후보 {N}건. 문서에 넣을 번호를 골라 주세요 (없으면 '없음')
   1. {회사}: {무엇을 했는지}, {확인한 수치} ({날짜}) {링크}
   ```
3. 작성자가 고른 것만 문서 외부 사례 표에 넣는다. 고르지 않은 것은 문서에 넣지 않는다
4. 비대화 환경이면 후보를 스펙 폴더 `research.md`에 저장만 하고 문서에는 넣지 않는다
5. `sources.md`에는 문서에 넣은 사례만 "외부: {제목}, {날짜}, {링크}"로 남긴다. 출처 등급은 "외부"

## 문서에 넣는 방법

- 외부 사례 표: 구분(같은 서비스, 비슷한 서비스, 외부 동향), 대상, 내용, 날짜, 출처
- 내용 칸에는 사실과 수치만. "벤치마크할 만함", "우리도 해야 함" 같은 판단을 쓰지 않는다
- 출처 칸은 링크. 원문 문장을 길게 옮기지 않는다
- 외부 수치를 문제의 데이터 묶음에 올릴 때는 외부 사례 표에 있는 것만, 본문에는 값과 무엇의 수치인지만, 출처와 날짜는 1-2 데이터 근거 펼치기에
- 회사 이름이 사내 기밀 판단과 닿으면(제휴 협상 중인 곳 등) 넣기 전에 작성자에게 묻는다

## 채팅 보고

- 찾지 못했으면 "최근 24개월 안의 외부 사례를 찾지 못했습니다" 한 줄. 억지로 채우지 않는다
- 오래된 자료만 있으면 "24개월이 넘은 자료만 있어 넣지 않았습니다: {제목} ({날짜})" 한 줄
