# 질문 매핑표

리뷰에서 정의 없음 또는 불충분으로 판정된 소항목과 초안의 빈칸 `[Q번호]`를 이 표의 질문으로 바꾼다. 답이 오면 지정된 섹션과 열에 채운다. 적용 유형이 맞지 않는 소항목은 묻지 않는다

## 질문 묶음 규칙

- 한 번에 5개 안팎. 대항목 순서(사용자 및 권한 → 정책 → 시나리오 → 기능 상세 → UI → 데이터)
- 선택지가 있는 질문을 먼저. AskUserQuestion 도구가 있으면 선택지형으로, 없으면 번호 목록으로
- 질문 문안의 `{기능}`, `{화면}` 자리는 초안의 실제 이름으로 채움
- 최대 2회. 2회 후 답이 없거나 "모른다", "나중에"인 항목은 본문의 해당 셀에 `⚠️ {항목} → {결정 주체} 확인 필요`로 남기고 지어내지 않음
- 답이 초안과 어긋나면 답을 채택하고 초안을 고침

기능 상세 명세

...
번호와 답만 적어 주세요. 모르는 것은 "모름"이라고 하면 문서에 확인 필요로 남깁니다.
